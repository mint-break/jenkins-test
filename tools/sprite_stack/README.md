# sprite_stack: 4方向図 → ボクセル → スライス帯

スライスは**必ずボクセルデータの断面から生成**します(層を絵として描くことはしません)。
スライス帯・ターンテーブル・.obj はすべて同じボクセル配列から出力されます。

```
# 目標の見た目(胴体9段の太い段 + 細かい葉、ドット絵描画)
python3 -m tools.sprite_stack --input input/views_pixel.png --part warm --remove-part --round 2.5 --out output/pixel_input/no_bread
```

- `--res`: ボクセルの高さ(形の解像度、既定 64)
- `--layers`: 胴体の段数(既定 9)。各段は厚み(数ボクセル)を持つ1枚のスライスになる
- `--top-layers`: 葉などの付属物の層数(既定 0 = 1ボクセルごと、薄い葉が崩れない)
- `--ridge`: 段の境目の溝と上端のハイライトの強さ / `--no-outline` / `--smooth`(ドット絵描画をやめる)
- `--grid auto`: 4つの図をシート上の位置から自動で見つける(1列・2×2・上1+下3などに対応)

依存: Python 3, Pillow, NumPy, SciPy (`pip install pillow numpy scipy`)

## パイプライン

1. **ビュー分割** (`views.py`): `--grid auto` の場合、横長(4x1)か2x2かを自動で判定します。`--order` で並び順を指定します(既定 `top,front,side,back`)。
   背景は透過(alpha)、またはしきい値 `--bg-threshold` 以下の暗い色として判定します。最大成分の25%未満の連結成分(ラベル文字など)は捨てます。
2. **Visual Hull** (`voxelize.py`): 高さ = `--layers` とし、正面/側面/背面の各ビューを同じ高さに揃えます。
   上面図は正面の幅 × 側面の奥行に強制的に合わせます。背面は左右反転したうえで、IoU 最大になる位置で正面に揃えます。
3. **パーツ分割** (`--part warm` または r,g,b を使った numpy 式): 色で分離できる持ち物(ここではパン)について、
   各ビューで「胴体の輪郭から飛び出した画素」に投影されるボクセルだけを、遮蔽を考慮して削ります。Visual Hull のゴーストを除くための処理です。
   パンに隠れて見えない胴体の輪郭端は、上下の行から補間して推定します。
4. **細い付属物** (`--appendage auto`): 正面図のくびれ(葉の付け根)より上は、Visual Hull で作ると厚い板になります。
   そこで、正面シルエット × 側面の中心線に沿った厚さ `--plate` の板として作り直します。
5. **着色**: 表面ボクセルごとに、見えているビューの中で法線と最も向きが合うビューから色を投影します。
   どのビューからも見えない面は、最寄りの色で補完します。パーツ画素はパーツのボクセルにだけ塗ります。
6. **任意**: `--round 2.5` で各層を超楕円に丸めます。`--colors N` で減色します。
7. **出力**
   - `slices.png`: 横一列のスライス帯。左が地面側。各層は上から見た図で、キャラの正面が下端です。`slices_x8.png` は拡大版です。
   - `slices.json`: スライス帯のメタ情報(`layer_bottom` / `layer_thickness`: 各層の下端と厚み)
   - `turntable_16.png` / `turntable.gif`: ライティングなし
   - `turntable_16_lit.png` / `turntable_lit.gif`: 法線ライティングと Voxel AO あり
   - `compare_flat_vs_lit.png`: 上から、ライティングなし / 26近傍の法線そのまま / ぼかした法線
   - `model.obj`: Greedy Meshing、頂点カラー付き(`v x y z r g b`)
   - `compare_stack_vs_mesh.png`: スタック描画と .obj 描画を並べたもの
   - `report.json`: スライス帯を読み戻した結果がボクセルと一致するか、メッシュの面積が露出面の数と一致するかの自己チェック

## 段(厚い層)の作り方

胴体は `--layers` 個の帯に分け、各帯の中央の断面を形にします。外周の色は帯の高さ全体の
表面色を投影し、帯の代表色から大きく外れる色(目・頬・線画)を優先するので、段の間に
細かい部分が埋もれません。描画では各層を厚み分だけ1pxずつ重ね、最下段を暗く(段の溝)、
最上段を明るく(縁のハイライト)します。.obj も各層を厚み分押し出した同じ段の形です。

## パンなし版とブラウザビューア

- `--part warm --remove-part`: パンを各ビューから消して胴体として作り直します(出力は `output/no_bread_32`, `output/no_bread_64`)。
- `output/viewer.html`: スライス帯をそのまま重ねて回すブラウザ用ビューアです。`output/` で `python3 -m http.server` を起動して開きます。
  自分のスライス帯を読み込んで確認することもできます。

## 座標と向きの約束

- 正面図 = -Z 側から見た図、背面図 = +Z 側から見た図
- 側面図 = -X 側から見た図で、キャラは画面の**左**を向く
- 上面図 = 真上から見た図で、キャラの正面が画面の**下**
- 右側面図は無いので、左側面図を流用する(着色時の優先度は少し下げる)

## プレビュー描画

各層を共通のピボット(層の中心)で回転し、`--squash` 倍に縦に潰します。そのうえで、1層ごとに 1ボクセル(=`--scale` px)ずつ持ち上げて、下の層から順に重ねます。
すべての層が同じピボットと同じ整数オフセットで描かれるので、構造上、層同士はずれません。
